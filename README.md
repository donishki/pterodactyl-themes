# Pterodactyl Themes

An independent Pterodactyl v1.15.2 fork with an admin theme manager for presets, branding, appearance controls and portable ZIP theme packages.

[Theme guide and setup](THEMES.md) · [Upstream project information](README.upstream.md) · [MIT license](LICENSE.md)

## Included

- Admin → Themes with Original, Midnight, Forest and Daylight presets.
- Color, font, corner-radius and HTTPS logo customization.
- Live editor preview, ZIP import/export and reset to the original appearance.
- Shared styling across the admin, user and login interfaces.

Theme packages contain validated settings, not executable code. Existing third-party theme frameworks are not compatible. See [THEMES.md](THEMES.md) for the package format, build instructions and verification.

This repository contains source code only. Deployment secrets, accounts, databases and game files are never included. Pterodactyl attribution and the original MIT license are retained.
